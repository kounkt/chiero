この方針は、CHIERO YouTube Localと関連する本人用Xクライアントに適用します。運営者は株式会社CHIERO、お問い合わせ先はinfo@chiero.jpです。

取得する情報と利用目的

YouTubeのチャンネルID・名前・ハンドル、本人が指定した動画・字幕・サムネイル・公開設定、XのユーザーID・ハンドル・本人が指定した投稿内容を、宛先確認と依頼された操作に利用します。

Googleの許可画面では動画・評価・コメント・字幕の編集や削除を含む共通権限が表示されます。実行内容は本人の依頼で決めます。Xでは本人の投稿とメディア送信、プロフィール・投稿状態の読み取り、継続接続の権限を使います。

保存と保護

OAuthクライアント情報、アクセストークン、更新用トークンは本人のMacの非公開認証フォルダに保存します。フォルダとファイルは本人だけが読める権限に設定します。許可されたアカウントID、接続確認時刻、操作結果IDは作業記録として保存します。

外部への通信と共有

認証とAPI操作ではGoogle・YouTube・Xの公式サーバーへ通信します。AIアシスタントによる作業確認には、本人IDや操作結果の読み取り情報を渡すことがあります。ローカル認証ストアの秘密値をAIへの入力や公開成果物へ含めない設計です。

データを販売・再配布したり、広告の対象リストや一般モデル学習用データセットへ加工する機能はありません。Google APIから受け取る情報は、Google API Services User Data PolicyのLimited Use要件に従って取り扱います。

許可の取消と削除

GoogleはGoogleアカウントの接続管理、Xは接続アプリの管理から許可を取り消せます。本人がローカル認証ストアを削除すると保存した認証情報を消去できます。作業記録の削除はinfo@chiero.jpへご連絡ください。
