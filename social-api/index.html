CHIERO YouTube Local

2026年9月30日

株式会社CHIEROが、本人所有のYouTubeチャンネルを公式APIで操作するためのローカルツールです。関連するXのクライアントと合わせて、CHIEROのSNS運用に使います。

機能

YouTubeのチャンネル確認、動画・字幕・サムネイルのアップロード、動画の公開設定を管理します。Xのクライアントは本人プロフィールの確認と原稿からの投稿作成に使います。接続確認では本人のIDを読み取ります。

利用範囲

本人のMacで、本人の依頼と授権に沿って実行します。第三者向けサービスとしての配布やアカウント登録は受け付けていません。

認証

GoogleとXのOAuthによる本人の許可を使います。認証情報はMacの非公開フォルダに保存し、API呼出しとトークン更新をローカルの処理で行います。
