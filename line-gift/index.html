無料で使える4つ

AI を仕事に使う時に、すぐ使える無料の4つです。

AI に制作を頼む前の、Mac の整え方

無料のガイドと、環境チェック（check_env.sh）。動画・LP・文章の制作に使う道具が Mac に入っているかを、一覧で確かめられます。

GitHub で開く

preflight-reviewer（無料の点検スキル）

AI が作った文書を、出す前に別のセッションで点検します。4つの観点の採点と、出してよいかの Yes／No を返します。Claude Code と Codex で使えます。

GitHub で開く

AI社員一式の説明書（無料の note）

AI社員一式を入れたら何ができるようになるかを、18の担当・作れる物・頼み方で見せる記事です。

note で読む

AI実践キット（無料）

メールアドレスを登録すると、AI を仕事に使う教材を受け取れます。

登録のページを開く
