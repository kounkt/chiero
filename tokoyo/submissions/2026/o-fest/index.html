Made entirely by one person. Equations, drawing, sound and editing — CHIERO, Fukuoka, Japan, 2026.

About the work

Each creature is written as a single equation. Nothing is drawn. No randomness, no clock and no external data are used, so it appears in the same form every time it is run, by anyone. Each chapter opens with the actual equation of the creature that follows. The sound is generated from the same equations as the image.

All equations are published and can be copied and run by anyone: chiero.jp/tokoyo/en
