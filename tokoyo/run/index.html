RUN AN EQUATION — TOKOYO

  1. 作品の頁で「式をコピー」を押す
  2. 下の枠に貼る
  3. 「走らせる」を押す

Copy an equation from any work page, paste it below, and run. The same creature appears — no randomness, no clock, so it is the same for everyone.

うまく走らないとき

式は (i, t, …) => [x, y] の形です。「式をコピー」で取ったものを、 欠けなくそのまま貼ってください。数字を書き換えるのは自由です——姿が変わります。 それも作品の一部です。

式は誰のものでもありません。持ち帰って、書き換えて、走らせてください。
ここに貼られた式はあなたの画面の中だけで走り、どこにも送られません。
