Run an equation

常世 — 式を走らせる

  1. Press Copy the equation on any work page
  2. Paste it into the box below
  3. Press Run

作品の頁で「式をコピー」を押し、下の枠に貼って「走らせる」。 乱数も時計も使っていないので、誰の画面でも同じ一体が現れます。

If it will not run

An equation has the form (i, t, …) => [x, y]. Paste exactly what Copy the equation gave you, with nothing missing. You are free to change the numbers — the creature changes with them. That is part of the work.

The equations belong to no one. Take them, rewrite them, run them.
Whatever you paste here runs inside your own screen only, and is sent nowhere.
